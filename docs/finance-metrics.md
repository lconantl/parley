# Экономические показатели: формулы и специфика РСБУ

Источники строк: форма 0710001 «Бухгалтерский баланс», 0710002 «Отчет о финансовых
результатах», 0710004 «Отчет о движении денежных средств», 0710003 «Отчет об изменениях
капитала».

## Откуда берутся строки

| Источник | Что даёт | Ограничение |
| --- | --- | --- |
| Checko / OFData `/finances` | Полная БФО по кодам строк, 2011–текущий год, значения **в рублях** | Основной источник |
| DaData `findById/party` → `finance_history` | Только агрегаты: 1100, 1200, 1300, 1400, 1500, 1600, 1700, 2100, 2110, 2200, 2300, 2400, 2410, 2500, 4100, 4200, 4300, 4400, 6100, 6400 | Нет 2120, 2210, 2220, 1210, 1230, 1250, 1520, 4221 — оборотный капитал и CAPEX не выводятся |
| DaData `finance` | income / revenue / expense / debt / penalty за один год | Грубый фолбэк |

**Знаки.** В БФО расходные строки приходят отрицательными: 2120, 2210, 2220, 2330, 2350,
4120, 4220, 4221, 4320, 4322. При извлечении берём модуль и дальше работаем с
положительными величинами.

**Формы отчётности.** Малые предприятия сдают упрощённую форму: часть строк отсутствует
физически, а не «не заполнена». Это нормальный сценарий, а не ошибка данных.

## Отчёт о финансовых результатах

| Показатель | Формула | Коды |
| --- | --- | --- |
| Выручка | строка напрямую | 2110 |
| Рост выручки | `Выручка(t) / Выручка(t−1) − 1` | 2110 |
| CAGR за 3 года | `(Выручка(t) / Выручка(t−3))^(1/3) − 1` | 2110 |
| Себестоимость | `|2120|`, фолбэк `2110 − 2100` | 2120, 2100 |
| Валовая прибыль | `2100`, фолбэк `2110 − |2120|` | 2100 |
| Коммерческие расходы | `|2210|` | 2210 |
| Управленческие расходы | `|2220|` | 2220 |
| Операционные расходы | `|2210| + |2220|` | 2210, 2220 |
| EBIT | `2200`, фолбэк `2300 + |2330|` | 2200, 2300, 2330 |
| EBITDA | `EBIT + Амортизация` | — |
| Проценты к уплате | `|2330|` | 2330 |
| Прибыль до налогообложения | `2300` | 2300 |
| Налог на прибыль | `|2410|` | 2410 |
| Эффективная ставка налога | `|2410| / 2300` | 2410, 2300 |
| Чистая прибыль | `2400` | 2400 |

**Амортизация в РСБУ не раскрывается** ни в балансе, ни в ОФР — она есть только в пояснениях
(бывшая форма 5), которых в API нет. Поэтому EBITDA в чистом виде не считается. Порядок
приближения:

1. Если известны CAPEX (4221) и основные средства на начало и конец периода:
   `Амортизация ≈ ОС(t−1) + CAPEX − ОС(t)`. Игнорирует выбытия и переоценку, поэтому
   уверенность низкая (~0.35).
2. Иначе — оценка ИИ по отраслевой норме амортизации к основным средствам.

Отсюда же следует, что **EBITDA российской непубличной компании — всегда приблизительная
величина**, и это нужно показывать пользователю, а не выдавать за факт.

## Маржинальность

`Валовая маржа = Валовая прибыль / Выручка`, аналогично операционная, EBITDA, чистая и
FCF-маржа. Все — к выручке (2110).

## Денежные потоки

| Показатель | Формула | Коды |
| --- | --- | --- |
| Операционный поток (OCF) | `4100` | 4100 |
| Инвестиционный поток | `4200` | 4200 |
| Финансовый поток | `4300` | 4300 |
| Чистый поток за период | `4400` | 4400 |
| CAPEX | `|4221|` (платежи за приобретение и создание ВНА) | 4221 |
| FCF | `OCF − CAPEX` | 4100, 4221 |
| Денежные средства | `1250` | 1250 |
| Конверсия прибыли в поток | `OCF / Чистая прибыль` | 4100, 2400 |

Если ОДДС не сдан (упрощённая отчётность), 4100 и 4221 отсутствуют. Тогда OCF оценивается
ИИ или через косвенный метод, а CAPEX — через прирост внеоборотных активов.

## Оборотный капитал

| Показатель | Формула | Коды |
| --- | --- | --- |
| Запасы | `1210` | 1210 |
| Дебиторская задолженность | `1230` | 1230 |
| Кредиторская задолженность | `1520` | 1520 |
| Оборотный капитал | `(1210 + 1230) − 1520` | — |
| DIO | `365 × Запасы / Себестоимость` | — |
| DSO | `365 × Дебиторка / Выручка` | — |
| DPO | `365 × Кредиторка / Себестоимость` | — |
| Денежный цикл | `DIO + DSO − DPO` | — |

Строго корректнее брать средние остатки за период, но в БФО удобно доступен только остаток
на конец года, поэтому считаем по конечным остаткам и помечаем это как допущение.

## Долг и структура капитала

| Показатель | Формула | Коды |
| --- | --- | --- |
| Долгосрочный долг | `1410` | 1410 |
| Краткосрочный долг | `1510` | 1510 |
| Совокупный долг | `1410 + 1510` | — |
| Чистый долг | `Совокупный долг − 1250 − 1240` | — |
| Чистый долг / EBITDA | `Чистый долг / EBITDA` | — |
| Покрытие процентов | `EBIT / |2330|` | — |
| Долг / собственный капитал | `Совокупный долг / 1300` | — |

Важно не путать **весь пассив** (1400 + 1500) с **процентным долгом** (1410 + 1510):
кредиторская задолженность 1520 — не долг.

## Баланс

Активы `1600`, пассивы `1700`, собственный капитал `1300`, внеоборотные `1100`,
оборотные `1200`, краткосрочные обязательства `1500`, основные средства `1150`,
НМА `1110`, результаты НИОКР `1120`, нераспределённая прибыль `1370`.

## Ликвидность и платёжеспособность

| Коэффициент | Формула | Норма для РФ |
| --- | --- | --- |
| Текущая ликвидность | `1200 / 1500` | 1.5–2.5 |
| Быстрая ликвидность | `(1230 + 1240 + 1250) / 1500` | ≥ 1.0 |
| Абсолютная ликвидность | `(1240 + 1250) / 1500` | ≥ 0.2 |
| Автономия | `1300 / 1700` | ≥ 0.5 |
| Z-счёт Альтмана (непубличные) | `6.56·X1 + 3.26·X2 + 6.72·X3 + 1.05·X4` | > 2.6 — безопасно, < 1.1 — риск |

где `X1 = (1200 − 1500)/1600`, `X2 = 1370/1600`, `X3 = EBIT/1600`, `X4 = 1300/(1400 + 1500)`.

## Эффективность капитала

| Показатель | Формула |
| --- | --- |
| Эффективная ставка налога | `|2410| / 2300`, фолбэк — 25 % с 2025 года, 20 % ранее |
| NOPAT | `EBIT × (1 − ставка)` |
| Инвестированный капитал | `1300 + 1410 + 1510 − 1250` |
| ROE | `2400 / 1300` |
| ROA | `2400 / 1600` |
| ROIC | `NOPAT / Инвестированный капитал` |
| ROCE | `EBIT / (1600 − 1500)` |
| Оборачиваемость активов | `2110 / 1600` |

Ставка налога на прибыль в РФ: 20 % до 2024 года включительно, **25 % с 2025 года**
(ФЗ № 176-ФЗ от 12.07.2024). Для УСН и других спецрежимов эффективная ставка считается
по факту из 2410, а не по номиналу.

## Инвестиции и НИОКР

`CAPEX / Выручка` — интенсивность инвестиций. Отдельной строки расходов на НИОКР в РСБУ
нет: капитализированные разработки лежат в строке `1120`, текущие расходы растворены в
себестоимости и управленческих расходах. Поэтому `researchExpense` почти всегда пробел
под оценку ИИ, а `1120` используется как нижняя граница.

## Акционерная отдача

`Дивиденды выплаченные = |4322|`, `Выкуп долей и акций = |4321|`.

Для ООО понятия «количество акций», EPS, P/E неприменимы — есть уставный капитал `1310` и
доли участников. Такие показатели помечаются как неприменимые, а не как пробел. Для ПАО и
АО количество акций и котировки в БФО отсутствуют — источник только внешний (ИИ, биржа).

## Оценка стоимости

| Показатель | Формула |
| --- | --- |
| Рыночная капитализация | цена акции × число акций (только публичные) |
| EV | `Капитализация + Чистый долг` |
| P/E | `Капитализация / Чистая прибыль` |
| EV/EBITDA | `EV / EBITDA` |
| EV/Revenue | `EV / Выручка` |
| P/FCF | `Капитализация / FCF` |
| P/B | `Капитализация / 1300` |

Для непубличной компании капитализация оценивается ИИ через отраслевые мультипликаторы
российского рынка. Российские мультипликаторы систематически ниже западных: EV/EBITDA
у публичных компаний РФ обычно 3–6x против 10–14x в США, поэтому подставлять западные
бенчмарки нельзя.

## Качество прибыли

| Показатель | Формула |
| --- | --- |
| Разовые доходы | `2340` (прочие доходы) |
| Разовые расходы | `2350` (прочие расходы) |
| Нормализованная чистая прибыль | `2400 − (2340 − 2350) × (1 − ставка)` |
| Accrual ratio | `(2400 − 4100) / 1600` |

Прочие доходы и расходы не полностью разовые, поэтому нормализация — верхняя оценка
эффекта, и уверенность у показателя понижена.

## Чего в отчётности нет вообще

Ни в одной форме РСБУ не раскрываются: сегменты бизнеса, количество и концентрация
клиентов, удержание, средний чек, доля рынка, размер рынка, отраслевые операционные метрики
и выручка конкурентов в сопоставимом виде. Всё это закрывается только внешними источниками
и оценкой ИИ. Юридические риски частично собираются из данных Checko (арбитраж,
исполнительные производства, проверки) и DaData (недостоверные сведения, статус).
