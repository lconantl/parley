# Проверка поставки

Проверено 28.09.2026.

- Release-сборка: GCC 13.3, C++20, Ubuntu 24.04 x86-64, CMake 3.28.3.
- Компиляция с `-Wall -Wextra -Wpedantic -Werror`.
- 30 автотестов GoogleTest прошли.
- Проверены персональные реакции, сохранение после перезапуска, история отмены, устаревшие и повторные кнопки, страницы избранного, завершение ленты, выбор сценария и четыре текста.
- Ошибка отправки после лайка не удаляет пару из избранного.
- Проверены запрет доступа посторонним, запрет работы с данными в группах и блокировка второго процесса с той же базой.
- Все 100 карточек укладываются в лимит длины. Проверены экранирование HTML и разбиение кириллицы/эмодзи с точным восстановлением текста.
- SQLite: 100 пар, 400 обращений, целостность и внешние ключи проверены. В начальной базе нет пользовательских реакций.
- `bash start.sh --check` успешно проверяет базу без Telegram.

Тесты Telegram выполнялись с имитацией API. Отправки через настоящий токен и сборки на Windows не выполнялись. Первый запуск на вашем сервере проверит токен, доступность Telegram и список разрешённых пользователей.
